## 线路和 IP：比价格更影响体验的两件事

香港到大陆的线路按优化程度大致分几类。三网直连精品线（CMI/CU2/CN2）对移动、联通、电信都做了去程优化，综合最稳；CN2 GIA 是电信双向精品，电信用户延迟低，联通移动一般；CMI 偏移动国际精品；9929 是联通精品；普通 BGP 自动选路，延迟均衡但高峰期不如专线稳。不确定自己宽带走哪家，选三网直连覆盖面最广。

LightLayer 的促销款把带宽拆成三个口径写：香港特价机是 10M 优化、15M 全向、20M 国际，洛杉矶机是 50M 优化、200M 全向、300M 国际。优化带宽是给大陆方向用的，国际带宽是出海用的，三个数字不能相加，买之前先想清楚流量主要往哪边走。

IP 属性决定能干什么。原生 IP 归属地是香港，Netflix、Disney+ 港区能直接开；住宅 IP 来自 HGC、iCable 这类本地宽带运营商，纯净度高，TVB 直播、Cityline 购票这类本地服务能用；机房 IP 最便宜，流媒体平台识别率高，Netflix 经常直接拒绝。LightLayer 的定价页和促销信息都没写 IP 归属类型，要解锁港区内容的话，下单前先问清楚，别指望机房 IP 能顶上。

虚拟化方式上，KVM 是完整硬件虚拟化，资源独占，Docker、WireGuard、自定义内核模块都能跑；OpenVZ 共享宿主内核，这些都受限制。日常使用优先 KVM。

## 哪些人不该买最便宜那档

- **要解锁 TVB、Netflix 港区、Cityline 购票**：机房 IP 再便宜也不合适，得先确认有住宅或原生 IP 的款。

- **只需要 1Mbps 跑个轻量代理**：不用上高配，Startup 这一档就够，多花的钱买不到额外体验。
- **要跑 Windows 且配置要求高**：LightLayer 提供 Windows，但低价档的内存和端口是给小负载准备的，重负载场景要往上选。
- **对退款保障有硬要求**：先确认条款再付款，别把“应该能退”当默认。

## 常见问题

**月付还是年付？**

LightLayer 促销规则里写了默认季付、半年、年付另有折扣，优惠码还能和长周期折扣叠加。年付的问题是会锁住资金，先用月付跑一两个周期，确认线路和稳定性符合预期再转年付更稳。

**流量超了会直接断网吗？**

云服务器三档标的是不限流量，HK-VP04 标 1TB。超过之后的处理方式，公开页面没有写明，是限速还是别的策略需要下单前问客服。行业里常见做法是限速而非断网，但不能套用到具体商家。

**便宜套餐能装 Windows 吗？**

LightLayer 官方 FAQ 写明支持 Linux，需要时也提供 Windows。具体哪个档位能选、要不要额外授权费，在结算页的操作系统选项里能看到。

**香港节点真的不用备案？**

香港机房不在 ICP 备案范围内，网站放上去不需要备案就能对大陆开放访问，这是它相对大陆节点的直接优势。域名解析、CDN、支付通道各自的合规要求另算，免备案只解决服务器这一环。

**$4/月和 $5.6/月差在哪？**

Startup 是 1 核 1G、100M 端口，买定后不能升配。Pay As You Go 从 2 核 2G、200M 端口起步，可以随时加配置。差 1.6 美元买到的是后续可扩展的余地，打算长期用、业务会长大的话，这 1.6 美元值得花。
